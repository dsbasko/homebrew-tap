# homebrew-tap

Homebrew tap for [dsbasko](https://github.com/dsbasko)'s tools.

## Install

```bash
brew install dsbasko/tap/dndmode
```

Or tap first, then install:

```bash
brew tap dsbasko/tap
brew install dndmode
```

## Formulae

| Formula | Description |
|---------|-------------|
| [`dndmode`](https://github.com/dsbasko/dndmode) | Keep macOS awake and shield all displays with a black lock overlay (Apple Silicon, macOS 14+). |
